    [ADP] 1. 데이터 이해 - 데이터의 이해

    2025년 12월 22일(수정: 2025년 12월 23일)

    데이터와 정보

    데이터 정의

    추론과 추정의 근거를 이루는 사실, 다른 객체와 상호 관계 속에 가치를 가짐.

    데이터 특성

    • 존재적 특성: 객관적 사실(Fact, Raw Material)
    • 당위적 특성: 추론, 예측, 전망, 추정을 위한 근거(Basis)

    데이터 유형

    • 정성적 데이터(Qualitative Data): 비정형, 주관적, 저장/검색/분석에 많은 비용 소모
    • 정량적 데이터(Quantitative Data): 정형, 객관적, 적은 비용 소모

    차이점 확인

    지식경영 핵심 이슈

    • 암묵지: 경험 지식, 공유 어려움, 개인에게 축적된 내면화(Internalization) 지식 → 조직의 지식으로 공통화(Socialization)
    • 형식지: 문서 지식, 공유 용이, 숫자나 언어로 표출화(Externalization) 지식 → 개인의 지식으로 연결과(Combination)

    데이터와 정보의 관계

    DIKW의 정의

    • 데이터(Data): 객관적 사실, 개별로 의미 중요 X
    • 정보(Information): 데이터 가공, 처리 후 의미 O
    • 지식(Knowledge): 정보 구조화, 개인 경험 결합으로 고유의 지식으로 내재화
    • 지혜(Wisdom): 지식 축적 및 아이디어 결합된 창의적 산물

    DIKW 피라미드

    데이터, 정보, 지식을 통해 지혜를 얻는 계층구조 설명

    예시) 피라미드에서는 하단부터 데이터 → 지혜 순서
- A 마켓의 펜 100원, B 마켓 펜 200원 → 데이터
- A 마켓의 펜이 더 쌈 → 정보
- 더 싼 A 마켓의 펜을 사려함 → 지식
- A 마켓의 다른 문구류도 B 마켓보다 쌀거라 생각 → 지혜

    데이터베이스의 정의와 특징

    용어의 연혁

    • 1950년대 : 미국 군대 군비 상황 관리를 위해 컴퓨터 도서관을 설립. 데이터 기지 → Data Base
    • 1963년 6월 : SDC가 데이터베이스 용어 공식사용
    • 1963년 : GE의 C.바크만이 DBMS인 IDS 개발
    • 1965년 : 데이터베이스 시스템 용어 등장
    • 1970년대 초반 : 유럽에서 데이터베이스 용어 일반화
    • 1975년 : 미국 CAC가 KORSTIC을 통해 서비스 → 우리나라에서 데이터베이스 사용
    • 1980년 : KORSTIC이 TECHNOLINE 이라는 온라인 정보 검색 서비스 개시 → 본격적인 데이터베이스 서비스 시대
    • 1980년대 중반 : 국내 데이터베이스 관련 기술 연구 개발

    내용

    변화되는 데이터
    Changeable Data
    		저장 내용은 곧 현시점 상태. 단, 삽입, 삭제, 갱신으로 변화되도 현재의 정확한 데이터 유지

    자주 출제됨. 특징 맞거나 틀린 것 선택

    데이터베이스의 다양한 측면에서의 특징

    • 정보의 축적 및 전달
      • 기계 가독성 : 일정한 형식 → 컴퓨터(정보처리기기) 읽고 쓰기 가능
      • 검색 가독성 : 다양한 방법 → 검색 가능
      • 원격 조작성 : 원거리에서 즉시 이용
    • 정보 이용 : 원하는 다양한 정보를 신속 정확하고 경제적으로 찾아냄.
    • 정보 관리 : 질서, 구조에 따라 정리, 저장, 검색, 관리 → 축적, 추가, 갱신 용이
    • 정보기술 발전 : 정보처리, 소프트웨어, 하드웨어, 네트워크 등 발전
    • 경제/산업 : 인프라 특성으로 경제, 산업, 사회 활동 효율 → 국민 편의 증진 수단

    데이터베이스의 활용

    기업 내부 데이터베이스

    정보통신망 구축 가속화 → 1990년대 기업 내부 데이터베이스가 전사 시스템으로 확대

    1980년대

    • OLTP(On-Line Transaction Processing): 여러 단말에서 요청 → 호스트가 DB 엑세스 → 처리결과 리턴
    • OLAP(On-Line Analytical Processing): 정보 분석, 비즈니스 관점으로 데이터 접근 및 의사 결정에 도움되는 정보 획득 기술.

    약어의 의미 확인, OLTP → 데이터 갱신, OLAP → 데이터 조회

    2000년대

    • CRM(Customer Relationship Management) : 고객관계관리, 기업이 고객 관련 내외부 자료 분석통합 → 고객 중심 자원 극대화 → 고객 특성 마케팅 활동을 계획, 지원 평가
    • SCM(Supply Chain Management) : 공급망관리, 기업에서 공급망 단계 최적화 → 수요자의 제품을 원하는 시간과 장소에 제공

    각 분야별 내부 데이터베이스

    1. 분야별 데이터 베이스 개념

    • 제조
      • 2000년 기점 전환, 클라이언트/서버 내부 정보시스템 → 웹기반 DB 전환 중
      • 대기업 위주 ERP → CRM 발전, 중소기업 투자 확대 필요성 인지. RTE를 통한 협업적 IT 비중 확대
    • 금융
      • 1998년 IMF 이후 확산
      • 2000년대 초, EAI, ERP, e-CRM으로 정보 공유 및 통합 → 고객 정보 전략적 활용
      • 2000년대 중, DW(Data Warehouse) 도입 → DB활용 마케팅 강화, 최적화를 위한 BI 기반 시스템 구축
      • 바젤2 같은 대형 프로젝트 마무리 이후 EDW(Enterprise Data Warehouse)확장이 DB 시장 확장에 기여
    • 유통
      • 2000년 이후, IT 환경 변화에 따라 CRM, SCM 구축 활발
      • 상거래 인프라 및 KMS 백업시스템 구축 진행
      • RFID 등장 → 유비쿼터스 시대 준비

    2. 분야별 데이터 베이스 소개

    • 제조
      • ERP(Enterprise Resource Planning) : 경영자원 통합 시스템으로 재구축 → 생산성 극대화, 경영혁신기법
      • BI(Business Intelligence) : 의사결정에 활용하는 일련의 프로세스
      • CRM(Customer Relationship Management) : 고객 중심 자원 극대화
      • RTE(Real-Time Enterprise) : 새로운 기업경영시스템, 회사 전 부문의 정보를 하나로 통합.
    • 금융
      • EAI(Enterprise Application Integration) : 정보를 중앙 집중적 통합, 관리, 사용 가능한 인프라
      • EDW(Enterprise Data Warehouse): BPR, CRM, BSC 같은 다양한 분석 어플리케이션들을 위한 원천
    • 유통
      • KMS(knowledge Management System) : 지식관리시스템, 기업 경영을 지식 관점에서 접근.
      • RFID(Radio Frequency, RF) : 주파수를 이용해 ID를 식별하는 시스템 → 전자태그

    사회기반구조로서의 데이터베이스

    1. 개념

    • 1990년대 사회 각 부문의 정보화로 DB 구축 활발
    • 부가가치통신망(VAN)으로 정보망 구축
    • 1990년대 후반 지리, 교통 DB 구축
    • 2000년대 고도화 → 일반 가정에서 정보 쉽게 습득

    2. 종류

    • EDI(Electronic Data Interchange) : 무역에 필요한 서류들을 표준화된 양식으로 전자적 신호로 변경 → 통신망으로 거래처 전송
    • VAN(Value Added Network) : 부가가치통신망, 공중 전기통신사업자의 통신회선으로 독자 네트워크 형성
    • CALS(Commerce At Light Speed) : 전자상거래 구축을 위한 경영통합정보시스템, 제품의 라이프 사이클 데이터 통합자료를 공유, 교환 가능.

    3. 분야별 사회기반 구조의 데이터베이스

    • 물류
      • CVO(Commercial Vehicle Operation System, 화물운송정보)
      • PORT-MIS(항만운영정보시스템)
      • KROIS(철도운영정보시스템)
    • 지리/교통
      • GIS(Geographic Information System, 지리정보시스템)
      • RS(Remote Sensing, 원격탐사)
      • GPS(Global Positioning System, 범지구위치결정시스템)
      • ITS(Intelligent Transport System, 지능형교통시스템)
      • LBS(Location Based Service, 위치기반서비스)
      • SIM(Spatial Information Management, 공간정보관리)
    • 의료
      • PACS(Picture Archiving and Communications System)
      • U헬스(Ubiquitous - Health)
    • 교육
      • NEIS(National Education Information System, 교육행정정보시스템)
