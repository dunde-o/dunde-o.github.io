    [ADP] 1. 데이터 이해 - 데이터의 이해

    2025년 12월 22일 오후 02:59(수정: 2025년 12월 24일 오전 10:39)

    데이터와 정보

    데이터 개념

    데이터: 추론과 추정의 근거가 되는 객관적 사실. 다른 객체와의 관계 속에서 가치 발생.

    데이터 특성

    존재적 특성

    • 객관적 사실 그 자체 (Fact, Raw Material)

    당위적 특성

    • 추론, 예측, 전망의 근거 (Basis)

    데이터 유형

    구분정성적 데이터정량적 데이터
    형태비정형정형
    성격주관적객관적
    비용높음낮음

    정성적 데이터는 비정형/주관적/고비용, 정량적 데이터는 정형/객관적/저비용으로 구분됨

    지식의 분류

    암묵지 (Tacit Knowledge)

    • 경험으로 축적, 공유 어려움
    • 개인에게 내면화(Internalization)
    • 조직으로 전파 시 공통화(Socialization) 필요

    형식지 (Explicit Knowledge)

    • 문서로 존재, 공유 용이
    • 언어/숫자로 표출화(Externalization)
    • 연결화(Combination)로 확산

    DIKW 피라미드

    데이터에서 지혜로 이어지는 지식의 계층 구조.

    단계정의예시
    Data개별적으로 의미 없는 객관적 사실A마켓 펜 100원, B마켓 펜 200원
    Information데이터 가공/처리로 의미 부여A마켓 펜이 더 저렴함
    Knowledge정보 구조화 + 개인 경험 결합A마켓에서 펜 구매 결정
    Wisdom지식 축적 + 창의적 아이디어 결합A마켓 다른 문구류도 저렴할 것으로 추론

    DIKW 각 단계별 정의를 예시와 함께 이해할 것. 피라미드 구조상 Data가 가장 하단, Wisdom이 최상단

    데이터베이스의 정의와 특징

    용어의 연혁

    시기내용
    1950년대미국 군대, 군비 관리용 컴퓨터 도서관 설립 → Data Base 개념 등장
    1963년SDC 심포지엄에서 데이터베이스 용어 공식 사용
    1963년GE의 C.바크만, DBMS인 IDS 개발
    1970년대 초유럽에서 용어 일반화
    1975년미국 CAC → KORSTIC 통해 국내 도입
    1980년KORSTIC의 TECHNOLINE 서비스 → 본격 DB 서비스 시대
    1980년대 중반국내 DB 기술 연구개발 본격화

    데이터베이스 정의

    1차 개념 (정형 데이터)

    • 체계적/조직적으로 정리된 데이터 집합
    • 전자적 수단으로 개별 접근 가능
    • 소재를 체계적으로 배열하여 검색 가능하도록 구성

    2차 개념 (비정형 데이터 포함 → 빅데이터)

    • 복수 업무 지원 가능한 데이터 집합
    • 복수 이용자 요구에 대응
    • 문자, 기호, 음성, 화상, 영상 등 다양한 콘텐츠 포함
    • 다양한 용도/방법으로 활용 가능한 정보 집합체

    데이터베이스 정의는 1차 개념(정형 데이터)에서 2차 개념(비정형 데이터 포함)으로 확장됨

    데이터베이스 특징

    4대 특징

    특징설명
    통합된 데이터 (Integrated)중복 최소화. 중복은 관리상 부작용 유발
    저장된 데이터 (Stored)컴퓨터 접근 가능한 저장 매체에 저장
    공용 데이터 (Shared)여러 사용자 공동 이용 → 대용량, 복잡한 구조
    변화되는 데이터 (Changeable)삽입/삭제/갱신으로 변화하며 현재 상태 유지

    4대 특징(Integrated, Stored, Shared, Changeable)과 각 설명을 정확히 연결할 수 있어야 함

    기타 특징

    정보 축적/전달

    • 기계 가독성: 일정 형식 → 컴퓨터 읽기/쓰기 가능
    • 검색 가능성: 다양한 방법으로 검색
    • 원격 조작성: 원거리 즉시 이용

    정보 이용: 신속, 정확, 경제적 검색

    정보 관리: 체계적 정리/저장 → 축적/추가/갱신 용이

    기술 발전: 정보처리, SW, HW, 네트워크 발전 촉진

    경제/산업: 인프라로서 사회 활동 효율화, 국민 편의 증진

    데이터베이스의 활용

    기업 내부 데이터베이스

    1990년대 정보통신망 구축 가속화 → 기업 내부 DB가 전사 시스템으로 확대

    OLTP vs OLAP

    1980년대 등장한 두 가지 데이터 처리 방식.

    OLTP (On-Line Transaction Processing)

    • 여러 단말 요청 → 호스트 DB 접근 → 결과 리턴
    • 핵심: 데이터 갱신

    OLAP (On-Line Analytical Processing)

    • 정보 분석, 비즈니스 관점 데이터 접근
    • 핵심: 의사결정 지원

    OLTP는 트랜잭션 처리(데이터 갱신), OLAP은 분석 처리(데이터 조회/의사결정)가 핵심 기능

    2000년대 시스템

    CRM (Customer Relationship Management)

    • 고객관계관리
    • 고객 데이터 분석/통합 → 고객 중심 자원 극대화 → 맞춤 마케팅

    SCM (Supply Chain Management)

    • 공급망관리
    • 공급망 단계 최적화 → 적시적소 제품 제공
